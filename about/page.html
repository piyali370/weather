GeoWeather

About This App

The GeoWeather App is designed to provide accurate, real-time information about cities across the globe, including their region, country, time zone, latitude, longitude, and local time. For every selected city, the app presents key information such as its region, country, and time zone, along with precise latitude and longitude coordinates. In addition, it shows the local time of the location, helping users stay aware of time differences worldwide. It is designed to be simple, fast, and user-friendly.

Features

  • 🌐 Latitude & Longitude Tracking
  • 📍 Location Details
  • 🕒 Live Time Display
  • 🌍 Timezone Insights
  • ⚡ Fast and responsive design

Developer

This project is developed as part of a learning journey in web development. It uses HTML, CSS, and JavaScript along with weather APIs.
